# GitHub 主页手动修改指南

你的主页：<https://github.com/lkuko>

主页源码：<https://github.com/lkuko/lkuko>

## 最简单的修改方法

1. 打开 [README 在线编辑页](https://github.com/lkuko/lkuko/edit/main/README.md)，使用 `lkuko` 登录。
2. 找到要改的内容，直接改文字或链接。源码里的 `<!-- 01 … -->` 到 `<!-- 06 … -->` 是编辑标记，不会出现在主页上。
3. 点击 **Preview** 查看效果，确认表格和链接正常。
4. 点击 **Commit changes…**，填写修改说明，选择直接提交到 `main`，再确认提交。
5. 回到主页刷新。文字通常很快更新；动画图片可能受 GitHub 图片缓存影响，稍等后再查看。

平时只需要编辑根目录的 `README.md`。这份指南放在 `docs` 中，不会直接显示在个人主页里。

## 修改标题、颜色和速度

原版动画中的文字是：

```text
lines=Hi%2C+I'm+AILICute.;AI+Agent+%C2%B7+Full-Stack+Explorer
```

例如想改成昵称加一句英文介绍，可以替换为：

```text
lines=Hi%2C+I'm+YourName.;Building+useful+things
```

- `+` 表示空格，`;` 分隔轮播的多句话。
- 中文可先粘贴到 [Readme Typing SVG](https://readme-typing-svg.herokuapp.com/demo/) 生成器中，再复制生成的图片地址。
- `color=0078D7` 是字体颜色，可换为其他六位十六进制颜色值，不加 `#`。
- `size=20` 是字号；文字变长时可调小字号，或缩短文字。
- `duration=3000` 是每句话的打字时长，单位为毫秒。
- `pause=1800` 是两句话之间的停顿时间。
- `width=560` 是动画画布宽度。调整时，同步修改 `<img>` 上的 `width="560"`。

动画依赖第三方图片服务，服务不可用时浏览器可能显示 `alt` 文字。如果想改成普通标题，直接将整个 `<img … />` 替换为：

```html
<h2>Hi, I'm AILICute 👋</h2>
```

## 添加邮箱、B 站或博客

在 `03 导航链接` 处，按现有格式添加链接。将示例中的邮箱、主页地址换成你准备公开的信息：

```html
  ·
  <a href="mailto:your-public-email@example.com">Email</a>
  ·
  <a href="https://space.bilibili.com/你的UID">Bilibili</a>
  ·
  <a href="https://你的博客域名">博客</a>
```

也可以在右栏 `📡 开源与交流` 下添加：

```markdown
- 📺 [Bilibili](https://space.bilibili.com/你的UID)
- 📝 [我的博客](https://你的博客域名)
```

## 替换项目或改成工作经历

左栏每个项目使用同一种结构：

```html
<p>
  <strong><a href="https://github.com/lkuko/你的仓库名">项目名称</a></strong><br/>
  <code>技术一 · 技术二 · 技术三</code><br/>
  用一句话说明项目做什么。
</p>
```

如果想改成经历，把 `#### 💻 项目实践` 改成 `#### 💼 工作经历`，再替换每个项目块：

```html
<p>
  <strong>公司或团队名称</strong><br/>
  <code>职位 · 起止时间</code><br/>
  填写你实际负责的工作和成果。
</p>
```

保留外层 `<table>`、`<tr>`、`<td>` 及其结束标签。Markdown 标题、列表前后保留空行；两栏交界的 `</td>`、`<td …>` 和最后的结束标签保持顶格，避免被当成代码。两栏始终按表格显示，手机上内容会变窄，项目简介尽量简短。

## 头像、昵称、侧栏简介和置顶项目

这些信息不由 README 控制，需要在 GitHub 上单独修改：

- **头像**：进入 [个人资料设置](https://github.com/settings/profile)，在头像处选择编辑并上传图片。
- **昵称与侧栏简介**：在同一设置页修改 **Name**、**Bio**、**URL** 等字段并保存。当前昵称为 `AILICute`，简介为“跟随阿库娅女神，加入阿库西斯教吧！”。
- **README 中的一句话简介**：这是独立文字。修改侧栏 Bio 后，如需保持一致，也要修改 README 的 `02` 部分。
- **置顶项目**：在 [个人主页](https://github.com/lkuko) 的仓库区域选择 **Customize your pins**，选择想展示的仓库后保存。

## 在电脑上修改

本地源码目录是 `E:\githubpr\lkuko`。如果你在网页上改过，先拉取最新版本，再编辑：

```powershell
cd E:\githubpr\lkuko
git pull --ff-only
notepad README.md
git diff
git add README.md
git commit -m "Update profile"
git push
```

`git diff` 用来确认本次改动。若修改指南本身，也将相应文件加入提交。

## 主页显示规则与恢复

- 仓库必须叫 `lkuko`，与账号名相同，并保持 **Public**；主页文件必须位于默认分支根目录，名称为 `README.md`。
- 这是 GitHub 个人主页 README，不需要部署 GitHub Pages、安装依赖或配置域名。
- 修改出错时，可打开 [README 历史记录](https://github.com/lkuko/lkuko/commits/main/README.md)，查看旧版本，复制需要恢复的内容，再编辑当前文件并提交。
- GitHub 会过滤自定义脚本与许多 CSS，建议沿用现有 HTML/Markdown 结构。
